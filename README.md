Карта знаний R&D для горно-металлургической отрасли (Платформа GraphRAG)
Проект разработан в рамках хакатона Норникель AI Science Hack, Трек 2 Научный клубок.

Описание проекта
Система представляет собой интеллектуальную поисково-аналитическую платформу управления знаниями Норникеля. Она обрабатывает научно-технические отчеты, патенты и статьи, извлекает метаданные и структурирует их в единый семантический граф знаний. В основе системы лежит гибридный подход GraphRAG, объединяющий векторный семантический поиск Qdrant и графовые связи Neo4j.

Ключевые возможности

Гибридный поиск GraphRAG: Сочетание семантических векторов Yandex Embeddings со строгими путями в Neo4j.

Автоматический сравнительный анализ: Построение сводных таблиц сравнения параметров из графа.

Автоматическая генерация гипотез (Link Prediction): Прогнозирование скрытых связей между процессами и материалами на базе ИИ.

Аудит качества знаний: Автоматическое выявление противоречий в параметрах между отчетами.

Соответствие требованиям ИБ: Ролевая модель доступа и ведение журнала аудита действий.

Структура проекта

config/settings.py: Валидация настроек и среды.

src/core/neo4j_client.py: Пакетная транзакционная запись в Neo4j через UNWIND.

src/core/qdrant_client.py: Управление коллекциями векторов и поиск в Qdrant.

src/core/yandex_ai.py: Модуль интеграции с локальной Ollama и облачной Yandex AI Studio.

src/pipeline/: Модули ETL (загрузка документов, нарезка чанков, извлечение и линковка сущностей).

src/services/: Бизнес-службы поиска, GraphRAG, генерации гипотез и выявления противоречий.

ui/app.py: Главный файл интерфейса Streamlit.

Системные требования

Docker и Docker Compose

Python 3.10 или выше

Локальный сервис Ollama (для локальной работы без интернета)

Инструкция по установке и запуску

Запуск баз данных
Выполните команду в терминале для поднятия контейнеров Neo4j и Qdrant:
docker compose up -d

Настройка файла окружения
Создайте файл с именем .env в корневой папке проекта и добавьте следующие параметры:
YANDEX_AI_STUDIO_API_KEY=your_actual_api_key_here
YANDEX_FOLDER_ID=b1ggusvist6c2sia1dno
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=very_strong_password_123
QDRANT_HOST=localhost
QDRANT_PORT=6333
AI_MODE=LOCAL
MOCK_MODE=False

Параметр AI_MODE может принимать значения LOCAL (для локальной работы через Ollama) или CLOUD (для работы через облако Yandex AI Studio). Параметр MOCK_MODE=True включает быстрый демонстрационный режим.

Загрузка локальных моделей (для режима LOCAL)
В терминале вашего компьютера выполните команды скачивания моделей в Ollama:
ollama pull qwen3.5
ollama pull nomic-embed-text

Установка зависимостей Python
Активируйте виртуальное окружение и установите пакеты:
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

Запуск веб-приложения
Запустите интерфейс Streamlit:
streamlit run app.py

Пакетная индексация папок (опционально)
Для индексации целых локальных каталогов документов выполните:
python src/pipeline/bulk_ingest.py
